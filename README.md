# 马孔多 · Macondo

《百年孤独》改编的短篇叙事游戏。**两分钟一遍，七个结局。**

> 屏幕上的每一个字都是范晔译本的原文，一个字都没改。
> 我只做减法：从九千多字里挑出有电的那几句，其余全删。

## 它是什么

不是把小说做成 RPG，是让一个看不懂这本书的人，两分钟摸到它。

```
开场：多年以后，面对行刑队……
  ↓
共同开头：磁铁、万物皆有灵、梅尔基亚德斯死了
  ↓
羊皮卷上写着这家人还没发生的一百年，你只能读一条
  ↓
七个意象选一个 → 那个人的一生 → 他的结局
```

七代人 = 七种孤独 = 七个结局。玩七遍，这本书就过完了。

| 选项 | 那个人 | 那种孤独 |
|---|---|---|
| 一场落了整夜的花雨 | 何塞·阿尔卡蒂奥·布恩迪亚 | 疯掉的 |
| 一条做好又熔掉的小金鱼 | 奥雷里亚诺·布恩迪亚上校 | 打完仗回不去的 |
| 一件自己缝的白衣裳 | 阿玛兰妲 | 把爱推开了的 |
| 一张飞走的床单 | 美人儿蕾梅黛丝 | 不属于人间的 |
| 一列开走的空火车 | 何塞·阿尔卡蒂奥第二 | 全世界只有你记得的 |
| 跟着火车的黄蝴蝶 | 梅梅 | 爱被掐死的 |
| 一队搬运婴儿的蚂蚁 | 奥雷里亚诺·巴比伦 | 读懂了但来不及的 |

当前进度：**上校**那条走得通（21 屏），其余六条还没画完。

## 三条铁律

1. **原文是权威。** 屏幕上的正文全部逐字来自原书，`tools/verify_verbatim.py` 会拿 epub 逐句校验，对不上就构建失败。
2. **短。** 一屏一句，图铺满，不给大段文字。
3. **画风统一。** 十九世纪铜版雕刻（Doré 那一路），所有插画共用一张风格锚点图。

## 跑起来

```bash
make run      # 启动游戏
make check    # 自检 autoload / 输入 / 场景 / 字体
make smoke    # 每个入口场景真跑 240 帧，有报错就失败
python3 tools/verify_verbatim.py   # 校验屏幕上的字是不是原文
```

需要 Godot 4.7+。配乐可选：往 `assets/audio/` 里丢 mp3/ogg/wav，开局自动循环。

## 目录

```
data/game.json          全部内容：开场 / 共同开头 / 选择 / 支线 / 结局
scenes/story.gd         播放器（一屏一句、淡入淡出、选择、结局）
art/scenes|branch|endings   铜版画插图
art/_anchors/           风格锚点
tools/verify_verbatim.py    逐字校验
tools/*_jobs.tsv        插画清单（图名 + 画面描述）
```

插画用 Codex 的 image_gen 批量出，流水线封装在 `~/.claude/skills/codex-image/`。
